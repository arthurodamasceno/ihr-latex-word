LaTeX IHR

Suplemento do Word para escrever em LaTeX e inserir no documento com os estilos do template de relatório do ICT Instituto Hercílio Randon.

Este endereço só hospeda os arquivos do suplemento. Para instalar, use o manifest.xml deste repositório (instruções no README).

Abrir o painel no navegador (os botões só funcionam dentro do Word).
